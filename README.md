
## Manage People

The **Manage People** module is part of the DVLD (Driving & Vehicle License Department) project. It provides functionality for managing people records within the system.

### Features

- Display all people in a DataGridView.
- Add new people to the system.
- Update existing people information.
- Delete people records.
- Search and filter people.
- Retrieve and manage data from SQL Server.

### Technologies Used

- C#
- Windows Forms (WinForms)
- SQL Server
- ADO.NET
- 3-Tier Architecture

### Overview

This module was developed to practice database operations, CRUD functionality, and the implementation of a layered architecture in a desktop application.

It helped strengthen my understanding of separating data access, business logic, and presentation layers to build maintainable and well-organized applications.
